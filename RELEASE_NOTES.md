# Release Notes

Le note di rilascio dettagliate per ogni versione sono pubblicate
automaticamente nella sezione
[Releases](https://github.com/kerneltrace/kerneltrace/releases) di
GitHub al momento della pubblicazione di un tag `v*.*.*` (vedi
`.github/workflows/release.yml`).

Questo file mantiene un indice di alto livello delle release principali;
per il changelog completo e continuamente aggiornato, vedi
[CHANGELOG.md](CHANGELOG.md).

## Formato delle release

Ogni release GitHub include:

- Il corpo estratto automaticamente dalla sezione corrispondente di
  `CHANGELOG.md`
- Archivi binari precompilati per `x86_64-unknown-linux-gnu` e
  `aarch64-unknown-linux-gnu`
- Note generate automaticamente da GitHub (lista dei commit inclusi)
